# 概率冲刺 · ProbSprint

> 7 天，把浙大《概率论与数理统计》第五版前三章盘明白。

**在线访问**：<https://fele-spec.github.io/probability-sprint/> · **源码**：<https://github.com/Fele-Spec/probability-sprint>

一个**纯静态、离线可用、零依赖**的一周冲刺学习平台。为浙江大学盛骤、谢式千、潘承毅《概率论与数理统计》第五版**第一章至第三章**设计：16 个小节、71 张主动回忆卡、94 道原创题（含提示与分步详解）、4 个交互实验室。

视觉上走「纸感游乐园」路线：骰仔吉祥物、可点击的概率星图、每日一签、7 天路线小站、任务贴纸、答题连击与彩屑反馈——但所有动画都尊重 `prefers-reduced-motion`。

学习机制不是拍脑袋：间隔复习、先猜后学、工作样例、交错练习、轻度游戏化——每条都有研究依据，详见平台内「方法」页和仓库里的 [研究笔记](研究笔记.md)。

## 快速开始

### 方式一：双击启动（推荐）

双击 **`启动学习平台.bat`**。脚本会：

1. 检查本地 8765 端口是否已在服务；
2. 没有的话用 Python 起一个本地静态服务器；
3. 自动打开 <http://127.0.0.1:8765/>。

关闭命令行窗口即停止服务。

### 方式二：手动启动

在项目目录执行：

```bash
python -m http.server 8765 --bind 127.0.0.1
```

然后浏览器访问 <http://127.0.0.1:8765/>。

> 也可以用 `py -m http.server 8765 --bind 127.0.0.1`（Windows 的 Python Launcher）。

### 方式三：直接打开

直接双击 `index.html` 也能用（Chrome / Edge）。但部分浏览器对 `file://` 下的 localStorage 有限制，**存档可能不保留**；长期使用建议方式一。

### 核心机制

- **间隔复习**：SM-2 风格的调度器（参考 FSRS 的“记忆稳定性”思想），按考试日封顶间隔。每日到期内容优先。
- **先猜后学**：知识卡默认“问题在前、答案在后”，先自己回答再翻面，利用预测试效应。
- **自动判分 + 自评**：选择、填空即时判分（分数/小数/百分数等价匹配，0.2% 容差）；计算题动手做完再看分步详解并自评，避免“看懂了”的错觉。
- **错题本**：做错的题自动进入，**连续答对 2 次**才移出；重练仍按间隔调度。
- **全真模拟**：20 道客观题、答题中不反馈、交卷统一批改，并记录历史最好成绩。
- **轻量游戏化**：XP、等级、连续天数、13 个成就；**没有排行榜、没有断签惩罚、没有内购、没有红点催促**。
- **数据全本地**：localStorage 单机存储，可导出/导入 JSON；无账号、无网络请求、无第三方依赖。

## 技术说明

- **零构建、零依赖**：原生 HTML + CSS + JavaScript（classic scripts），不需要 Node/npm 即可运行。
- **为什么不用框架**：这是个单人、离线、内容驱动的小工具，静态文件最稳；双击 .bat 就能用。
- **数学公式**：没有引入 MathJax/KaTeX，用 HTML + CSS 分数样式保证离线可用。复杂公式以分步文字解释为主。
- **测试**：`node test/validate.cjs` 校验 14 个 JS 文件语法、数据、SRS 调度与存档层；`flow.cjs` / `shots.cjs` 需要本地启动 Edge 调试实例（见脚本头部），用于开发期验证。

### 部署

本站由 **GitHub Pages** 从 `main` 分支根目录直接发布（纯静态，无需构建），推送到 `main` 后自动更新。Pages 地址：<https://fele-spec.github.io/probability-sprint/>。

## 数据与隐私

- 所有进度存在浏览器 `localStorage` 的 `probsprint.state.v1` 键下。
- 清理浏览器数据、换浏览器会丢失；「设置 → 导出 JSON」可备份，「导入 JSON」可恢复。
- 没有服务器、没有账号、没有埋点、没有外部请求。断网也能用。

## 已知限制

- 只覆盖前三章；数字特征、大数定律、统计推断不在范围内。
- 计算题为“自己演算 + 自评”，平台不能自动判断手写推导。
- 模拟测验采用固定顺序、即时交卷，不支持跳题/标记后返回。
- 单机存储，不支持多设备同步。
- 题量 94 道适合一周冲刺与二轮复习；若想长期刷题，建议扩充题库。
